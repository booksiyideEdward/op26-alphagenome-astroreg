# Reproducibility and redistribution boundary

## Included

- Focused OP26 analysis scripts and the fixed 1,000-permutation null diagnostic.
- Minimized relation-level AlphaGenome numerical outputs created by OP26.
- Machine-readable model, sensitivity, overlap and conditional-analysis results.
- Final manuscript figures and internal analysis records with their status labelled.

## Intentionally excluded

- AstroREG author tables: public source, but no repository-wide license was declared at audit; retrieval is from the official repository.
- AlphaGenome model weights and raw track outputs: unnecessary for reproducing the reported statistics and governed by separate terms.
- Complete ENCODE-rE2G, DNALONGBENCH and Murphy–Koo repositories: cited and retrieved from their maintainers rather than mirrored.
- API caches, temporary clones, high-resolution duplicate images and unrelated project files.
- API keys, access tokens, institutional credentials and browser state.

## AlphaGenome

Google DeepMind distributes the AlphaGenome client under Apache-2.0 and its examples/documentation under CC BY 4.0. API use is offered for non-commercial use subject to the AlphaGenome Terms of Use. OP26 does not redistribute Google code, weights or raw output tracks. The committed relation-level numerical scores are OP26 research outputs used to reproduce the paper's statistics.

## Freeze language

Analysis plans and freeze records were maintained within the project before the corresponding result inspection. They were not externally preregistered or independently timestamped. This public repository is a release archive only.
